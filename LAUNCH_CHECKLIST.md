# FULLDIAG launch checklist

## Before publication
- [ ] Select a production domain and configure HTTPS.
- [ ] Configure GitHub Pages or the selected host with this repository.
- [ ] Update the contact email if needed.
- [ ] Add the final absolute URL to sitemap.xml and reference it in robots.txt.
- [ ] Test every module on mobile and desktop.

## Before AdSense review
- [ ] Create an AdSense account with the owner’s legal, tax, and payment details.
- [ ] Add the site in AdSense and complete ownership verification.
- [ ] Add the AdSense script supplied by Google.
- [ ] Configure Google CMP / consent message for EEA, UK, and Switzerland visitors.
- [ ] Add ads.txt after receiving the Publisher ID.
- [ ] Request review only after the site is publicly reachable and policies are live.
